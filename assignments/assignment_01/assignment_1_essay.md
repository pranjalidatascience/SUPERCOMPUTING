# Documented code for Computations Research Tasks

I think having documented code is very helpful in debugging issues in case of research cases or new developments in technology. It is also great for reproducibility or also advancing on the same technology. At the same time, if the original researcher is on leave, a different researcher can still continue to work on the project and use the documented code to get up to speed. If we have documented code, and are having debugging issues, it is really easy to pinpoint specifically to a line of code and amend it. Documented code also improves transparency and allows other researchers to review, validate, and build upon existing work more effectively.
