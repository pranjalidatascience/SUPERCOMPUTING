# SUPERCOMPUTING

DATA 440: Supercomputing for Science is a class in the Data Science Department at William & Mary's School of Computing, Data Science and Physics which 

- introduces computational data skills for scientists with a focus on genetic sequence data, command-line usage, and pipeline development. 

- develops competence in interacting with a remote high-performance computing environment

- applies the principles of project organization and reproducibility to create and benchmark analysis pipelines. 

- develops competence in installing, parsing, and linking novel computational tools.
